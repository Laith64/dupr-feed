# DUPR Feed

A pickleball activity timeline — like Instagram or Venmo, but for [DUPR](https://www.dupr.gg) matches. Follow players, track rating changes, compare head-to-head stats, and find people to play with.

## Features

- **Match feed** — Recent matches from players you follow and watch, sorted newest-first. Win/loss badges, scores, rating deltas, and tournament names.
- **Player profiles** — Tap any player name to see their DUPR ratings, match history, and stats.
- **Head-to-head** — Compare two players (or two teams) with win rates, score breakdowns, and match history.
- **Connect** — Find nearby players by city. Geo-search across city clusters with DUPR rating filters.
- **Globe view** — Browse top pros by region on an interactive globe.
- **Watch list** — Track any player's matches in your feed. Auto-seeded with top pros on first login.
- **PWA** — Installable as a home screen app on mobile.

## Tech stack

- **Backend:** Python 3.12, Flask, Gunicorn
- **Frontend:** Single HTML file with inline CSS/JS (no build step, no bundler)
- **API:** DUPR API (`api.dupr.gg`) with Bearer JWT auth
- **Concurrency:** ThreadPoolExecutor for parallel API fetches
- **Hosting:** Render.com (auto-deploys on push to `main`)
- **Design:** Glassmorphism dark theme, responsive (mobile + desktop)

## Quick start

```bash
git clone https://github.com/Laith64/dupr-feed.git
cd dupr-feed
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python server.py  # http://localhost:5001
```

Set `SECRET_KEY` in a `.env` file for production. `PORT` defaults to 5001.

## Project structure

```
server.py              # Flask backend — all API routes
templates/index.html   # Single-page frontend (HTML + CSS + JS)
watches.json           # Default watch list (committed)
watchlists/            # Per-user watch lists
static/manifest.json   # PWA manifest
requirements.txt       # Python dependencies
Dockerfile             # Container build
render.yaml            # Render.com deploy config
```

## Deployment

Hosted on [Render.com](https://render.com). Pushing to `main` triggers an automatic deploy.

```bash
git push origin main
```

Environment variables on Render:
- `SECRET_KEY` — required (auto-generated by Render)
- `PORT` — defaults to 5001
